نبذة مختصرة

مهندس أنظمة وممارس أمني متخصص في الأمن السيبراني وتطبيقات الذكاء الاصطناعي للأمن. مؤسس مشروع NAVA_AI البحثي لبناء أنظمة وكيل محلي داعم لمهام الأمن السيبراني. أمتلك خبرة عملية مع أنظمة Linux/Windows، شبكات، افتراضية، حاويات، وأدوات اختبار الأمان.

المهارات التقنية

  • أمن سيبراني (Penetration Testing, Network Security)
  • Linux & System Administration
  • برمجة: Python, C++, JavaScript, PHP, Dart/Flutter
  • الذكاء الاصطناعي المحلي ونظم الوكلاء (NAVA_AI)
  • حاويات وDevOps: Docker, Docker Compose, NGINX
  • قواعد بيانات: PostgreSQL, MySQL, SQLite

NAVA_AI — معماريّة أنظمة ذكاء محلية لوظائف الأمن
